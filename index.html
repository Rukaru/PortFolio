WORK 01

３マッチパズル×バトル

EMPIRE MATCH / 企業プロジェクト採択作品

新日本プロレス公式ゲーム採用作品。 新日本プロレス株式会社との企業連携プロジェクトで「グレート-O-カーン選手を用いたハイパーカジュアルゲーム」を制作。自分が出した企画がチーム案として採用され、メインプログラマーを担当しました。優秀作品として、新日本プロレス公式Webサイトに公式ゲームとして採用されました。
担当
メインプログラマー
使用
Unity / C#
制作期間
4ヶ月
人数
6人

ゲーム概要

3マッチパズルとバトルシステムを組み合わせたゲームです。プレイヤーがパズルを操作してタイルを消し、連鎖結果をバトル側へ反映させる仕組みを実装しました。

01 担当機能

  • 二次元配列によるパズル盤面とタイルの管理
  • タイルの交換、マッチ判定、消去、落下、補充処理
  • 状態管理によるパズルの進行制御
  • コンボ表示やタイルのハイライトなどの演出

02 開発で苦労した点・学んだこと

パズルの基本部分は動画教材を参考に学習し、その仕組みを理解しながら、バトルシステムとの連携に取り組みました。

当初は多くの処理を一つのスクリプトにまとめていたため、目的の処理を探すことや、既存の機能を変更することが難しくなりました。この経験から、機能ごとの役割を整理し、スクリプトを分けて管理することの重要性を学びました。

WORK 02

3Dドライビングミニゲーム

ミニゲーム / WheelCollider / ミニマップ

開発環境
Unity / C#
製作時間
7h
主な技術
Rigidbody、WheelCollider、Input System、Particle System

ゲーム概要

制限時間内に車を運転し、できるだけ長い距離を走行する3Dゲームです。車の操作や加速・ブレーキ、ミニマップなどを実装しました。

技術的な課題と工夫

車の加速が速すぎると操作が難しくなり、反対に遅すぎると運転の爽快感が失われることが課題でした。

そこで、実際の車の加速を参考にしながら、操作のしやすさと運転の気持ちよさの両立を目指しました。

WORK 03 開発中

2Dの発射ミニゲーム

作品名：［家まで飛ばす！］

開発環境
Unity / C#
製作時間
6h
主な技術
Rigidbody2D、AddForce()を使って放物線を描く発射処理

作品概要

プレイヤーをさまざまな方法で家まで飛ばす、コミカルなカジュアルゲームです。

技術的な課題と工夫

より発射感を出せるために、UnityのRigidbody2DとAddForce()を使用し、初速と重力によって放物線を描く挙動を実現しました。

実装にあたってはYouTubeの解説動画を参考にしました。参考コードの仕組みを理解しながら、自分のゲームの操作方法や仕様に合わせて調整することを目指しています。

作品概要
